\subsection{The Difference Lemma}

We present the proof of the difference lemma, formally:

\begin{lemma}[Difference Lemma]\label{lemma:difference_lemma}
    Let $\mathcal W_0, \mathcal W_1, \mathcal E$ be events with
    \[
        \Prob{\mathcal W_0 \land \lnot \mathcal E} = \Prob{\mathcal W_1 \land \lnot \mathcal E} 
    \]
    Then we can bound the difference in probability of $\mathcal W_0$ and $\mathcal W_1$ with
    \[
        \abs*{\Prob{\mathcal W_0} - \Prob{\mathcal W_1}} \le \Prob{\mathcal E}
    \]
\end{lemma}

\paragraph{Proof of \Cref{lemma:difference_lemma}.}
Let $\mathcal W_0, \mathcal W_1, \mathcal E$ be events and assume $\Prob{\mathcal W_0 \land \lnot \mathcal E} = \Prob{\mathcal W_1 \land \lnot \mathcal E}$.
Then we can deduce the following:
\begin{align}
    &\abs*{\Prob{\mathcal W_0} - \Prob{\mathcal W_1}}\\
    =& 
    \abs*{\Prob{\mathcal W_0 \land \mathcal E} + \Prob{\mathcal W_0 \land \lnot \mathcal E} - \Prob{\mathcal W_1 \land \mathcal E} - \Prob{\mathcal W_1 \land \lnot \mathcal E}}\\ 
    =& \abs*{\Prob{\mathcal W_0 \land \mathcal E} - \Prob{\mathcal W_1 \land \mathcal E}}\\ 
    =& \abs*{\Prob{\mathcal W_0 \mid \mathcal E} \Prob{\mathcal E} - \Prob{\mathcal W_1 \mid \mathcal E} \Prob{\mathcal E}}\\ 
    =& \abs*{\Prob{\mathcal W_0 \mid \mathcal E} - \Prob{\mathcal W_1 \mid \mathcal E}} \Prob{\mathcal E}\\
    \le&\Prob{\mathcal E} 
\end{align}

\subsection{Conjecture}

We quickly want to make a few remarks towards the idea of extending the proof of \Cref{lemma:warmup}
to the more general case of \Cref{conjecture}. The direct proof fails because of the subtle reason that 
the hidden oracle queries need to be candidate-wide irrelevant but not jointly irrelevant over queries to 
many distinct candidate schemes. In the proof of \Cref{lemma:warmup} we argue that for oracle $\O_2$
all hidden oracle queries, i.e. all oracle queries not contained in the transcript of the combiners
verification algorithm are exactly the queries that would influence the combiner output if changes.
On the other hand, for any arbitrary assignment of the hidden queries, the output of the combiner 
stays constant as long as the non-hidden queries and the queries to $\O_1$ are honestly answered.

This idea gives rise to the attack of iteratively filtering the secret key space on a polynomial number 
of points by keeping in every round $(1.)$ at least the true secret key, $(2.)$ only secret keys 
for which the output of the combiner is the same as for the true secret key. We argue that after a sufficient 
number of filtering steps, any remaining candidate has sufficiently high chance of evaluating to the same output 
as the combiner does with the true secret key on a uniformly random evaluation point.

However, since the hidden queries must not necessarily be jointly-irrelevant this argument cannot be applied if 
we have more candidates, of which still $n-1$ need to be secure for the combiner to be required to 
implement unique provability and pseudorandomness.
